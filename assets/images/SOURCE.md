# Where the pictures come from

Copied from the Windows 95 shell's icon set (wippy-windows/windows,
`assets/icons/SOURCE.md`): `regedit` at 32 and 16 px, Microsoft's artwork
from `shell32.dll`, extracted there from the original `.ico` files as RGBA
PNG. This is not part of the module under MIT; the file name is the
picture's name in the pack, `windows.regedit:images/regedit`.
